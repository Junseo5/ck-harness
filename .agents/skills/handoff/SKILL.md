# handoff

## README.md (프로젝트 루트, 기존 내용이 있으면 보존하고 섹션 추가)
1. 무엇인가: 한두 문장 (누가 무엇을 할 수 있게 되는가)
2. 실행 방법: 설치·실행 명령, 포트, 접속 경로. 복사해서 바로 되는지 직접 실행해 확인한다.
3. 결과: 핵심 수치 (예: 입력 120건 → 포함 97 / 제외 18 / 확인필요 5)
4. 검증: `docs/VERIFY.md` 요약 (PASS/FAIL 수, 남은 FAIL)
5. 문서 안내: PLAN · COLLAB · DECISIONS · VERIFY · HANDOFF

## docs/HANDOFF.md
- 현재 상태: 된 것 / 안 된 것
- 주요 결정: DECISIONS 중 핵심 3개 (이유 포함)
- 한계와 위험: `$risk-audit` 결과
- 다음 할 일: 우선순위 순 3~5개, 각각 담당자 확인 필요 여부 표시

## 규칙
- 문서에 없는 기능을 있다고 쓰지 않는다. 실행해 보지 않은 명령은 "미확인"으로 표시한다.
- 과장 없이, 숫자는 실제 실행 결과에서 가져온다.
- 끝나면 `docs: 인수인계 문서 정리` 로 커밋한다.
