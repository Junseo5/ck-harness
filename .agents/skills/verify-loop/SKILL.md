# verify-loop

이 세션은 검증 전용이다. 쓸 수 있는 곳은 `verify/`와 `docs/VERIFY.md`뿐이다.

## 1. 기준 확보
- `docs/PLAN.md`의 성공 기준, `docs/COLLAB.md`의 판단 기준과 예외를 목록으로 뽑는다.
- `src/`의 로직을 읽고 따라 하지 않는다. 결과물(출력 파일, API 응답, 화면)만 관찰 대상이다.

## 2. 검증 스크립트
- 스택에 맞는 뼈대를 채운다: `verify/check.py` 또는 `verify/check.mjs`.
- 원본 입력에서 기대값을 직접 계산하고, 결과물과 비교해 항목별 PASS/FAIL을 출력한다.
- 실행: `python3 verify/check.py` 또는 `node verify/check.mjs`.

## 3. 확인 항목 (순서대로)
1. 개수 대사: 입력 = 포함 + 제외 + 확인필요
2. 핵심 규칙 표본: 기준별 대표 사례 몇 건을 손으로 계산한 값과 비교
3. 경계값: 임계값 바로 위·아래, 빈 입력, 중복, 형식 오류, 결측
4. 인터페이스: 서버가 있으면 실제 요청(`curl`)으로 상태 코드와 응답 형태 확인

## 4. 기록과 보고
- `docs/VERIFY.md` 표에 항목/방법/기대/실제/판정을 채운다.
- FAIL은 고치지 않는다. 재현 명령과 함께 메인 세션에 넘길 한 줄 요약을 만든다.
- 판정할 수 없는 것은 "담당자 확인 필요"로 남기고 질문 문장을 만든다.
- `test: 독립 검증 추가` 로 커밋하고 3줄 보고(변경/확인/위험).
