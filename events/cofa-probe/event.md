## 이벤트: Cofa-Probe 실무형 AI 협업 과제

### 맥락
- 웹 IDE(E2B 샌드박스)에서 시나리오 속 **업무 담당자**의 요구를 메신저로 받아, 최대 180분 안에 동작하는 결과물을 만든다.
- 사용 가능한 AI는 제공된 Codex CLI뿐이다. 토큰 사용량, 대화, 터미널, git 기록, 작업 폴더 전체가 평가 자료로 수집된다.
- 제출 후 AI 없이 서술형 6문항(문항당 5분)이 이어지며, 문항은 제출물과 작업 기록에서 만들어진다.
  사람이 설명하지 못하는 코드는 감점 요인이다. 큰 변경은 나눠서, 이유를 남기며 진행한다.
- 평가에는 AI 평가도 함께 쓰인다. 요구에 없는 기능·과한 설계·쓰지 않는 파일은 완성도가 아니라 감점 요인으로 본다.
  담당자가 실제로 쓰는 장면에 필요한 것을 정확하고 단단하게 만드는 데 시간을 쓴다.

### 추가 규칙 (공통 규칙보다 우선)
- `git push`, 외부 업로드, 외부 전송 금지. 로컬 커밋만 한다.
- Computer Use·브라우저 자동화 기능은 쓰지 않는다. 화면 확인은 사람이 Browser 미리보기(0.0.0.0 바인딩)로 한다.
- 개인 API 키나 다른 AI 도구를 요구하거나 설정하지 않는다.
- 외부 자료로 결과물을 통째로 대체하지 않는다.
- 메모리 초과(OOM)는 구제되지 않는다. 서버·빌드를 겹쳐 띄우지 않고, 끝난 프로세스는 종료한다.

### 기준점 (과제 시작 기준 경과 시간)
0:30 범위 합의 · 1:30 기본판 동작 · 2:20 기능 동결 · 2:40 문서 마감 · 2:50 제출 시작

### 설명 예행연습 형식 (`$risk-audit`)
서술형 6문항, 문항당 4문장(250~450자): 결론(파일·함수 이름 포함) → 근거 → 한계 → 다음 검증.

### 제출 절차 (`$submit-check` 마지막 안내)
웹 IDE에서 '제출하고 문제풀기' → 미리보기 확인 → '제출물 확정하고 문제풀기'. 종료 10분 전까지.
