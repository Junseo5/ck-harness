# ck-harness

Codex CLI에서 **역할 프롬프트를 바로 꺼내 쓰기 위한** 개인 하네스입니다. 작업 폴더에 `AGENTS.md`와 역할 스킬 6개만 넣습니다.
과제 내용, 일정, 절차, 앱 코드는 들어 있지 않습니다. 과제 설명과 진행 방식은 그때그때 사람이 정합니다.

> **AI 에이전트에게**: 사용자가 이 저장소를 설치해 달라고 했다면 바로 아래 "설치" 절차만 따르면 됩니다.

## 설치

**1. 과제 작업 폴더의 맨 위**에서 다음 한 줄을 실행합니다. 저장소는 작업 폴더 밖(`/tmp`)에 받습니다.

```bash
git clone -q --depth 1 https://github.com/Junseo5/ck-harness /tmp/ck-harness && bash /tmp/ck-harness/install.sh
```

**2. 출력에 `[ck] 설치 끝`이 있으면 성공입니다.** 작업 폴더에 생기는 것은 이것뿐입니다.

```
AGENTS.md
.agents/skills/   ideate · spec · dev · strict · review · explain
```

**3. 사용자에게 알립니다.** "설치됐습니다. Codex를 종료하고 다시 실행(또는 `/new`)하면 `$dev`처럼 역할을 부를 수 있습니다."

### 막혔을 때

| 증상 | 처리 |
|---|---|
| `git clone`이 네트워크 오류로 실패 | 승인을 요청해 다시 실행합니다. 안 되면 사용자에게 터미널에서 실행해 달라고 합니다. |
| `/tmp/ck-harness`가 이미 있음 | `bash /tmp/ck-harness/install.sh`만 실행합니다. |
| `.agents` 쓰기가 거부됨 | 승인을 요청해 `bash /tmp/ck-harness/install.sh`를 다시 실행합니다. |
| `[ck] 커밋하지 못했습니다` | 파일 설치는 끝났습니다. 승인을 받아 출력에 나온 git 명령을 실행하거나 사용자에게 맡깁니다. |

### 설치가 하는 일

- 기존 파일을 덮어쓰지 않습니다. `AGENTS.md`가 있으면 뒤에 덧붙이고, 같은 이름의 다른 스킬이 있으면 건너뜁니다.
- 설치한 파일만 커밋합니다. 원격으로 보내지 않으며, 원격 연결이 없어도 됩니다.
- 작업 폴더나 git 루트가 홈 폴더여도 동작합니다. `~/.codex`는 건드리지 않고, 숨김 폴더와 캐시는 이 저장소의 git 제외 목록에 넣습니다.

## 쓰는 법

역할 스킬은 그 일을 가장 잘하는 사람의 프롬프트입니다. 세션을 켜고 불러서 일을 시키면 됩니다. 세션을 하나만 써도 되고, 세션마다 다른 역할을 맡겨도 됩니다.

| 이럴 때 | 부르기 | 이렇게 일합니다 |
|---|---|---|
| 방향이 안 정해졌다 | `$ideate` | 서로 다른 접근을 비교해 추천합니다. 코드는 쓰지 않습니다. |
| 요구를 정리해 명세를 쓴다 | `$spec` | 담당자 질문을 만들고, 근거를 밝혀 구현 가능한 명세를 씁니다. |
| 판단을 맡기고 구현한다 | `$dev` | 시니어 개발자로서 필요한 것만 단순하게 구현합니다. |
| 명세대로만 구현한다 | `$strict` | 명세를 벗어나지 않고, 모호하면 추측하지 않고 묻습니다. |
| 결과를 검증한다 | `$review` | 구현과 따로 확인해 요구 충족과 품질을 증거로 판정합니다. |
| 코드를 이해하고 설명한다 | `$explain` | 실제 코드를 근거로 구조와 이유를 설명하고 질문 대비를 돕습니다. |

```text
$spec 과제 README 읽고 담당자한테 물어볼 것부터 정리해줘
$dev docs/SPEC.md 기준으로 데이터 읽어서 요약 API까지 만들어줘
$strict docs/SPEC.md 2번 항목만 구현해줘
$review 지금 결과가 요구대로인지 확인해줘
$explain 입력 한 건이 어떤 함수를 거치는지 알려줘
```

창의가 필요하면 `$ideate`와 `$dev`를, 제약이 필요하면 `$spec`과 `$strict`를 고르면 됩니다.
역할을 부르지 않으면 평소의 Codex로 일합니다. 정해진 순서는 없습니다.

## 저장소 구조

```
AGENTS.md     작업 폴더에 들어가는 짧은 안내 (과제 내용 없음)
skills/       역할 스킬 6개
install.sh    설치 스크립트
```

새 역할은 `skills/<이름>/SKILL.md`를 추가하고 `AGENTS.md` 표에 한 줄 넣으면 됩니다.
